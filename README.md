# Keypath

Browser-based piano and guitar practice paths: staff + MIDI for piano, fretboard + mic for guitar, with coaching feedback and local progress.

## Try it

- Local: `npm install` then `npm run dev`
- GitHub Pages (when deployed): https://nugehs.github.io/piano-lesson/

## For schools

See the full **[Schools guide](docs/schools-guide.md)** for teachers and IT (classroom setup, privacy, schemes of work, limitations).

In the app, open **For schools** from the home path.

## Scripts
